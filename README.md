# 🐍 Neon Snake - Daily Fun Game

A cool neon-styled Snake game made with pure HTML5 Canvas and JavaScript!

## How to Play
- Open `index.html` in any modern browser
- Use **Arrow Keys** or **WASD** to control the snake
- Eat the glowing red food to grow and score points
- Avoid walls and yourself!
- Press **Space** to pause/unpause
- High score is saved in your browser

## Features
- Neon glow effects
- Particle explosions when eating food
- Smooth trail effect
- Local high score
- Responsive controls
